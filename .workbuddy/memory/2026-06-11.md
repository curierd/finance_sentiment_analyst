# 2026-06-11

## Docker 单机存储方案实施

根据 Notion 中的《Docker 单机存储方案（SQLite + 本地图片）》文档执行了完整改造：

### 1. 数据库适配器模式
- 创建 `backend/domain/repositories.py` — `CommentRepo` 和 `UnitOfWork` Protocol 接口
- 创建 `backend/adapters/sqlite/comment_repository.py` — SQLite 适配器实现，含 `SqliteUnitOfWork` 事务管理器
- `backend/database.py` — `get_db()` 自动应用 WAL + foreign_keys + synchronous=NORMAL + busy_timeout=5000
- `backend/config.py` — 新增 `DB_DRIVER`, `DB_DSN`, `UPLOAD_DIR`, `IMAGE_URL_PREFIX` 环境变量
- `backend/services/comment_service.py` — 改为从适配器导入（非原始仓库）

### 2. Docker 化
- `Dockerfile` — 多阶段构建（torch CPU 分离），非 root 用户 `app`，gunicorn 生产部署
- `docker-compose.yml` — 挂载 `./data/sqlite` 和 `./data/uploads`，端口 8000
- `.dockerignore` — 排除测试、缓存、开发文件
- `jobs/scripts/init_db.py` — Docker 入口点：首次运行自动建表 + 应用 PRAGMA

### 3. 图片路径迁移
- `jobs/scripts/migrate_images.py` — 迁移脚本：`comments/images/...` → `images/...`（相对 UPLOAD_DIR）
- `frontend/server.py` — 注入 `window.IMAGE_URL_PREFIX` 到 SPA，双路由 `/comments/` + `/uploads/`
- `frontend/index.html` — 图片 URL 使用 `IMAGE_URL_PREFIX` 变量
- `backend/routes/comment_routes.py` — 上传接口改为存入 `UPLOAD_DIR/images/<platform>/`

### 4. 备份
- `jobs/scripts/backup.py` — `.backup` API 备份 DB + tar.gz 打包图片，支持 `--keep` 天数自动轮转

### 测试结果
- 50 个测试全部通过（24 repo/service + 26 routes）
